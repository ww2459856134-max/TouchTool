# AutoJS HID 固件（ESP32-C3 / S3）

本目录存放与本 App「HID 触摸」功能配套的 ESP32 固件包。

- 固件包：`AutoJS-HID-ESP32-C3-S3-20260720.zip`（2026-07-20 版，支持 ESP32-C3 与 ESP32-S3）

## 刷机与使用

1. 解压固件包，按包内说明用浏览器刷机工具（flash 回）刷入 ESP32-C3/S3
2. **刷机后必须在手机蓝牙中重新配对**（取消配对 → 重新搜索连接 `AutoJS HID-xxxx`）
3. 设备首次使用连其热点完成配网，之后接入与手机相同的 WiFi
4. 在 App **设置 → HID 设备(ESP32)** 中配置设备 IP（可用「自动发现」扫描），端口固定 `21115`
5. 点击类动作（HID 中继 / 点击图片 / 点击坐标 / 手势 / 点击颜色 / 点击控件）的执行通道选「HID 触摸(ESP32)」

## 控制协议（App 侧实现，供参考）

- 传输：UDP 到设备 IP 的 `21115` 端口
- 载荷：1 字节指令 `0x06` + JSON
- JSON 格式（极简键名，抓官方 App 包对齐）：
  ```json
  {"a":[x1,y1,x2,y2],"b":300,"c":1200,"d":2670}
  ```
  - `a`：扁平坐标数组，按下与抬起同一点即为单击；多点为滑动/手势轨迹（坐标对 ≤199）
  - `b`：手势时长（毫秒，0~60000）
  - `c` / `d`：屏幕宽 / 高，固件据此映射为 digitizer 绝对坐标（0~32767）经蓝牙 HID 注入
- 注意：固件内还兼容旧版 `path/duration` 字段协议，但新版固件实际执行的是上述 `a/b/c/d` 格式

## 已知注意事项

- 手机需与 ESP32 在同一局域网；若开了「智能多网络/双 WLAN 加速」，UDP 包可能走蜂窝口导致不通
- 蓝牙显示「已连接」不代表可用，刷机后务必重新配对
